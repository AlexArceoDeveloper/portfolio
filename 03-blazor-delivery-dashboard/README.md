# Blazor Delivery Dashboard

Personal demonstration project for a Blazor interface connected to a .NET API.

## Implemented foundation

- Blazor UI with accessible components.
- API-backed delivery and quality metrics.
- Authentication boundary and role-aware views.
- xUnit coverage for the service layer.
- CI/CD documentation.
- No production, client or employer data.

## Run locally

```powershell
dotnet run --project src/DeliveryDashboard/DeliveryDashboard.csproj
```
